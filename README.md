# Workout Tracker

Este projeto é um rastreador de treinos Full Body, desenvolvido para ajudar no acompanhamento de rotinas de exercícios. Ele oferece uma interface simples para visualizar planilhas de treino e vídeos relacionados.

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estrutura da página.
*   **CSS3:** Estilização e layout responsivo.
*   **JavaScript:** Interatividade para alternar entre abas (planilha/vídeos).

## ✨ Funcionalidades

*   Visualização de planilhas de treino detalhadas.
*   Seção para vídeos de exercícios.
*   Design simples e funcional.
